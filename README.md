# Sovereign Cloud

This repository collects lightweight, offline-first engineering tools for sovereign cloud, resilience, security, migration-readiness, and infrastructure assessment workflows.

Each subdirectory is a standalone project with its own README, examples, tests, and package metadata.

## Projects

- `brownout-policy-compiler`
- `cabinet-burst-envelope`
- `dr-prereq-lint`
- `estate-triage`
- `gpu-rack-qualifier`
- `host-screen-contracts`
- `inference-placement-bench`
- `prompt-egress-guard`
- `rag-permission-canary`
- `s3-compat-replay`
- `stateful-storage-fit`

## Demo Documents

Business-story and demo writeups are collected in `demodocs/`.

## Notes

- The tools are designed to run locally.
- Generated output directories, dependency folders, caches, and build artifacts are ignored.
- Individual projects keep their own licensing, package metadata, and test suites.
